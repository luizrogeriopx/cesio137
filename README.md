# cesio137
O desastre do Césio-137 em Goiânia é considerado o maior acidente radiológico do mundo fora de uma usina nuclear (classificado como Nível 5 na Escala Internacional de Eventos Nucleares - INES). Ocorreu devido ao abandono de um aparelho de radioterapia nas ruínas de uma clínica desativada, desencadeando uma crise humanitária, médica e social.
